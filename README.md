# 🌍 DC Impact — Know the Cost of Every Forward Pass

**DC Impact** estimates the environmental footprint of AI model training and inference workloads. Plug in your hardware, cloud region, and runtime — get back carbon emissions (kg CO₂e), water usage (litres), and energy consumption (kWh) as a shareable report card ready to embed in your model card or README.

---

## What It Does

DC Impact takes your workload parameters — GPU/TPU type, cloud region, duration, and accelerator count — and runs them through real-world PUE, WUE, and regional grid carbon intensity data to produce accurate environmental estimates. Results are delivered as both a styled HTML badge and a structured JSON report. Everything runs locally with no external API calls; all hardware and emissions data is bundled.

---

## Quick Start

**Install**

```bash
pip install dc_impact
```

Or clone and run locally:

```bash
git clone https://github.com/your-org/dc_impact.git
cd dc_impact
pip install -e .
```

**Run the web app**

```bash
dc_impact
# → Serving on http://127.0.0.1:5000
```

Open [http://localhost:5000](http://localhost:5000), fill in your workload details, and click **Calculate**.

**One-shot API call**

```bash
curl -X POST http://localhost:5000/api/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "hardware": "a100",
    "region": "aws-us-east-1",
    "num_accelerators": 8,
    "duration_hours": 72,
    "utilization": 0.85,
    "workload_type": "training"
  }'
```

## Features

- **Three environmental metrics** — CO₂e emissions, water consumption, and energy draw computed from real hardware TDP and regional grid carbon intensity data.
- **Broad hardware & region coverage** — supports A100, H100, V100, TPU v4, and more; covers major AWS, GCP, and Azure regions with accurate PUE and WUE factors.
- **Embeddable report cards** — generates a styled HTML badge and structured JSON output ready to paste into GitHub READMEs or Hugging Face model cards.
- **REST API for automation** — `POST /api/calculate` integrates directly into CI/CD pipelines or post-training scripts.
- **Fully self-hostable, zero external dependencies** — all emissions and hardware data ships as static lookup tables; no API keys, no network calls.

## Usage Examples

### Web UI

Navigate to `http://localhost:5000`, select your hardware preset and cloud region, enter duration and accelerator count, and click **Calculate**. The report page shows your impact metrics and provides copy-pasteable embed snippets.

### REST API

```bash
# Calculate impact for an H100 inference job
curl -X POST http://localhost:5000/api/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "hardware": "h100",
    "region": "gcp-us-central1",
    "num_accelerators": 1,
    "duration_hours": 2.5,
    "utilization": 0.60,
    "workload_type": "inference"
  }'
```

### List Available Hardware & Regions

```bash
curl http://localhost:5000/api/hardware
curl http://localhost:5000/api/regions
```

### Python (programmatic)

```python
from dc_impact.calculator import calculate_impact

result = calculate_impact(
    hardware="a100",
    region="aws-us-east-1",
    num_accelerators=8,
    duration_hours=72,
    utilization=0.85,
    workload_type="training",
)

print(f"Energy:    {result.energy_kwh:.2f} kWh")
print(f"Emissions: {result.co2e_kg:.2f} kg CO₂e")
print(f"Water:     {result.water_liters:.2f} L")
```

### Embed in a README

After generating a report, copy the HTML snippet from the **Embed** section on the report page and paste it directly into your `README.md` or Hugging Face model card:

```html
<div class="report-card">
  <!-- generated by dc_impact — paste into your model card -->
  ...
</div>
```

## Configuration

DC Impact works out of the box with sensible defaults. For advanced use, set these environment variables before starting the server:

| Variable | Default | Description |
|---|---|---|
| `FLASK_ENV` | `production` | Set to `development` for debug mode and auto-reload |
| `FLASK_SECRET_KEY` | auto-generated | Session secret key; set explicitly in production |
| `DC_IMPACT_HOST` | `127.0.0.1` | Bind address |
| `DC_IMPACT_PORT` | `5000` | Listen port |

**Example:**

```bash
export FLASK_ENV=development
export DC_IMPACT_HOST=0.0.0.0
export DC_IMPACT_PORT=8080
dc_impact
```

**Running tests:**

```bash
pip install -e ".[dev]"
pytest
```
